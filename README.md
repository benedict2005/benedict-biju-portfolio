# Benedict Biju — Portfolio

Responsive single-page portfolio using HTML, CSS and vanilla JavaScript. Features smooth section navigation, active navbar section, mobile menu, project and experience sections, and a profile-click introduction-video placeholder.

## Add profile photo
The profile area currently uses a designed placeholder. To show your photo, upload it to `assets/profile.jpg`, then replace the `.portrait` button contents in `index.html` with an image element, keeping the button id `openVideo`.

## Add your introduction video later
Upload a video as `assets/intro.mp4`. Update the modal content in `index.html` to include a video element with controls and source `assets/intro.mp4`.

## Publish with GitHub Pages
Open repository **Settings → Pages**. Under Build and deployment choose **Deploy from a branch**, select `main` and `/(root)`, and save. The public URL will be shown in Pages settings.

Before publishing, replace the LinkedIn placeholder with your actual profile URL and verify contact details and academic/certification information.
